| Tier  | Name                     | Meaning                                                                                                                                  |
| ----- | ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **S** | **Super / Supreme Tier** | Outstanding, near-perfect. Significantly better than A-Tier. Often includes things that define best practices, game changers, or top 1%. |
| **A** | **Excellent Tier**       | High-performing and reliable. Not quite best-in-class, but solidly above average. Usually safe and smart choices.                        |
| **B** | **Good Tier**            | Competent, reliable. Gets the job done but may have limitations. Ideal for general use but not exceptional.                              |
| **C** | **Average Tier**         | Adequate but uninspiring. Functional, but has notable flaws or lacks edge.                                                               |
| **D** | **Below Average Tier**   | Subpar. Functional only in narrow cases or with effort. Outclassed by higher-tier alternatives.                                          |
| **F** | **Fail Tier**            | Broken, unreliable, outdated, or counterproductive. Use only if forced to, or never.                                                     |
