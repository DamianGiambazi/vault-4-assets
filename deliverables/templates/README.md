# The five contracts as templates

The novel's facts are replaced by `[slots]`. Fill every slot for your own work (strategy, legal, operations, code). The comments at the top of each file say how to run it and how to check its output outside the model.

| Template | Use it to | Check it with |
|---|---|---|
| `T1-RAW-OUTPUT.xml` | strip a long draft to its skeleton | count the items; scan for what must not be there |
| `T2-SURGICAL-FENCE.xml` | revise one zone inside fixed rules | an independent check of every self-reported field |
| `T3-HOSTILE-CRITIC.xml` | audit the result in a fresh chat | `../04-HOSTILE-CRITIC-RUBRIC.md` |
| `T4-MODALITY-SHIFT.xml` | turn prose into a state table | its shape, its UNKNOWNs, one row against your key |
| `T5-DERIVATIVE-MATRIX.xml` | three outputs from one source | the CSV imports; no unsupported claim; you type the commit |

**Always:** ask the receiver first (`../02-ASK-THE-RECEIVER.md`), seal a key before the run (`../05-THE-SEALED-KEY-PATTERN.md`), one contract per fresh chat.
The novel's versions are in `../novel/`; the originals as first written are in `../originals/`.
